# Bidah Outfit Collection

A small React and Vite catalogue website for Bidah Outfit Collection.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Catalogue imagery

Editorial reference photos are stored in `public/product-images` and sourced from [Unsplash](https://unsplash.com/license). They illustrate the collection styles and are not photos of Bidah's exact pieces; contact the designer for current designs, fabrics, and availability.
